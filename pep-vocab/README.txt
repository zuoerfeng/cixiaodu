Source project: https://github.com/cyforkk/pep-english-words
Source data: community-organized PEP 2019 vocabulary, originally converted from lilinji/English xlsx files.
Application code in the source project is MIT licensed. The vocabulary data is provided for learning/demo use and is not an officially licensed PEP dataset.
This local pack includes seven senior-high books and preserves their unit boundaries.
Chinese entries are shortened to the first semicolon-delimited dictionary sense for four-choice gameplay.
