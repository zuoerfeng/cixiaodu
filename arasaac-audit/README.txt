ARASAAC English pictogram metadata / high-school vocabulary audit
This package contains metadata candidates and downloaded PNG assets in images/.
All indexed pictograms are included, including extracurricular vocabulary.
Local curated scene photos are in photos/; original sources remain in the HTML visualWords entries.
Source: https://api.arasaac.org/v1/pictograms/all/en

Candidate matches are not verified illustrations of the intended dictionary sense.
The gk vocabulary list comes from local ECDICT tags, not a verified current curriculum list.
